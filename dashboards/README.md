# Dashboard recipes

`recipes.json` contains portable definitions and explicit resolver requirements, not instance-specific `dashboard.create` requests. Names, tags and item keys are resolved against the target instance during an administrator-controlled provisioning step. No numeric host/group/item/dashboard IDs are shipped.

First enable `networkexplorer` and widgets `neportpanel`, `netopology`, `neinterfacedetail`, `nedataquality`, `nefindings`. Import the LAB replay template only in the lab to exercise the inherited Overview/Connectivity/Diagnostics host pages. Production inherited host dashboards are created by future qualified template threads against the same module contracts. Never link the lab trapper template to a production network host.

The native Host navigator publishes `_hostid`; consumers use `override_hostid._reference=<reference>._hostid`. Port Panel publishes standard `_itemid` when a real interface scalar item is available; Interface Detail may consume `itemid._reference=<reference>._itemid`. Templates leave override fields absent so Zabbix supplies inherited host context. Do not invent new core broadcast types for VLAN/interface UID. Validate broadcasts and template override fields on each pinned release before shipping generated API payloads.

Provisioning must resolve explicit protected `site`/`ne.domain` tags and permitted host groups, verify globally unique host names, confirm widget registration, validate field schemas, cap scope, and prepare an ownership-tagged diff before writes. Share a dashboard only through administrator-approved sharing rules; sharing never grants host visibility. Preserve user-authored dashboards and export rollback definitions. A recipe's existence does not authorise replacement or production host linking.

Reports initially use on-demand permission-filtered tables and CSV/JSON: device/capability inventory, unresolved/ambiguous peers, management addressing/subnet annotations, intended-speed/LAG findings and collection quality. Automatic duplicate-address conflict reporting is later scope. Include generation time, observation ages and unknown coverage. CSV must neutralise spreadsheet formula prefixes. Native scheduled PDF is optional and requires the configured web service/browser/mail plus actual custom-widget print completion/asset/permission tests; no recipients or schedules are supplied here.

Optional business-service layer: prepare a separate proposal for organisation/site/agreed service trees using qualified problem tags. Availability/collection confidence are separate services. Redundancy/min-links/quorum/SLO semantics require explicit policy; LLDP adjacency and VLAN membership do not prove a business dependency or SLA. Do not create a service for every discovered link or mutate services from read requests.
